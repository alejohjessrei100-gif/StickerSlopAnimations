## Licence rules
- Safest: "Public domain" and "CC0". Use freely, still log the source.
- CC BY: attribute the author. CC BY-SA: attribute AND share-alike conditions may apply to derivative works. Check before using in a monetized video.
- The licence label is the uploader's claim. Open `file_page` and read the "Permission" and "Date" fields before relying on it, especially for "public domain" photos taken after ~1930.
- Always apply the Bible's rule: pre-1990 scenes = black-and-white or sepia background, hero in colour.
