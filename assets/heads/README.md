# CuriousMotionz-style cartoon heads (original, generated in code)

6 characters x 8 expressions + 1 mystery head = 49 transparent PNGs (1024 px wide, identical anchor so swaps do not jump).
Fully original artwork generated by `heads.py`, so there are no licence or copyright issues from third-party sources.

Characters: everyman, baker, elder, exec, teen, granny
Expressions: neutral, laugh, shock, angry, sad, sleepy, smug, worried
Special: `mystery_question.png` (black silhouette with white ?) for any unknown person (Bible section 2B)

Usage: erase the photo head from the body cutout, keep the neck, place the head with the chin overlapping the neck ~15%,
scale head height to ~22% of body height, match skin tone with a thin chin-join line. See `_contact_sheet.png`.

Edit `CH` in `heads.py` to add characters (skin, hair colour, style: short/messy/slick/bun/curlybun/balding, extras: glasses/mustache/stubble). Run `python3 heads.py`.
